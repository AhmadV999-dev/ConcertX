How to use ConvertX

01 • Choose a category Select Picture or Audio from the main ConvertX page.
02 • Choose your file Tap the Choose File button and select a supported file from your device.
03 • Select an output format Choose the format you want from the available options.
04 • Convert Press Convert File and wait for the conversion to finish.
05 • Download When the conversion is complete, press Download to save the converted file.
