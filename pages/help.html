How to use ConvertX

01 • Choose a category Select the type of file you want to convert.
02 • Choose your file Press Choose File and select a supported file from your device.
03 • Choose a format Select the output format you want.
04 • Convert Press Convert File and wait for the conversion to finish.
05 • Download When the conversion is complete, press Download to save your converted file.
