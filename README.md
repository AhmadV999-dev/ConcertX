# ConvertX

ConvertX is a simple, lightweight browser-based file conversion tool for
Pictures, Sound, and Video — built to run entirely as a static site on
GitHub Pages.

## Features

- Convert Picture, Sound, and Video files
- Clean, responsive layout (desktop and mobile)
- Light mode support
- File preview before conversion
- Progress bar during conversion
- Toast notification system for feedback
- No account or sign-up required

## Running on GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set the source to the branch containing
   these files (usually `main`) and the root (`/`) folder.
4. GitHub Pages will publish the site at:
   `https://<your-username>.github.io/<repo-name>/`

All internal links use relative paths, so the site works correctly both
locally and when hosted on GitHub Pages.
