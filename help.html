Here's how to use ConvertX in a few quick steps.

1. Choose a category

Pick Picture, Sound, or Video depending on the type of file you want to convert.

2. Select a file

Use the file picker on the card to choose the file from your device.

3. Choose an output format

Select the format you want to convert your file into from the available options.

4. Download the result

Once the conversion finishes, use the download button to save the converted file to your device.
