Privacy

ConvertX is hosted as a static site on GitHub Pages. Files you select for conversion are processed on your own device, in your browser. ConvertX does not upload your files to a server.

No account, sign-up, or personal information is required to use ConvertX.

If this changes in the future — for example, if conversions are ever processed through a server — this page will be updated to reflect that.
